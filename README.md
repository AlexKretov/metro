# Что день грядущий нам готовит? — прогноз загруженности метро

Домашнее задание по машинному обучению и временным рядам: построение прогноза почасовой
загруженности транспортной системы на основе данных [Metro Interstate Traffic Volume](https://archive.ics.uci.edu/ml/datasets/Metro+Interstate+Traffic+Volume) (UCI, почасовые измерения с `2012-10-02` по `2018-09-30`).

## Содержимое

|------|----------|

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate          # Linux/macOS
pip install -r requirements.txt

jupyter notebook notebooks/metro_forecast.ipynb
# или выполнить целиком:
jupyter nbconvert --to notebook --execute --inplace notebooks/metro_forecast.ipynb
```

## Этапы работы

1. **Загрузка и EDA** — только 4 нужные колонки (`traffic_volume`, `date_time`, `holiday`, `temp`).
2. **Очистка ряда** — удалены **7629 дубликатов**, ряд выровнен на почасовую сетку, **11 976** пропусков заполнены линейной интерполяцией → чистый ряд из **52 551** точек.
3. **Разделение** — последние 2 недели (336 точек) — отложенная выборка; прогноз на неделю = 168 точек.
4. **Релевантность истории** — эмпирически показано, что оптимально окно **~2 года** (вся 6-летняя история даже ухудшает качество).
5. **Модели** — Baseline, сезонный наивный, SARIMA (недельная сезонность), Linear Regression, Random Forest, Gradient Boosting.
6. **Финальный прогноз** на следующую неделю + доверительные интервалы (80% и 95%).

## Результаты (MAE на отложенной выборке — последние 2 недели)

| Модель | MAE | RMSE | MAPE, % | R² |
|--------|-----|------|---------|-----|
| **Random Forest** | **183.2** | **280.0** | **8.9** | 0.98 |
| Gradient Boosting | 192.5 | 282.2 | 9.8 | 0.98 |
| Сезонный наивный | 205.1 | 341.1 | 9.0 | 0.97 |
| Linear Regression | 247.9 | 367.1 | 14.4 | 0.97 |
| SARIMA (дневной m=7) + профиль | 337.9 | 440.0 | 23.4 | 0.95 |
| Baseline (среднее по weekday/hour) | 458.9 | 554.4 | 23.7 | 0.92 |

**Лучшая модель — Random Forest** (лаг 168 часов — ключевой признак, важность ≈ 0.89), она снижает ошибку прогноза на ~60% относительно baseline.
